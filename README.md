# 组件规范与无障碍说明编辑台（sologsb-1028）

面向设计系统维护者的组件契约编辑台。项目从零搭建，不是单页占位稿；组件、属性、状态、键盘行为、读屏说明、禁用场景和代码示例均使用真实数据模型，并自动保存到浏览器 `localStorage`。

## 功能

- 组件目录与全文搜索：可搜索组件名称、属性、键盘行为、读屏说明和示例代码。
- 分组编辑器：概述、属性与状态、无障碍、关联示例、版本与迁移、修订与留痕六个工作区。
- **权限隔离**：组件字段归规范组、属性契约（属性 + 交互签名）归平台组、无障碍说明归无障碍组、示例归平台组；每个编辑区标注责任组，旧数据缺责任组时自动补默认归属并留痕。
- **跨组修订流程**：非责任组的修改不会直接生效，而是进入该组件的待审修订草稿；发起组自动确认，涉及区的责任组确认后（至少两个责任组）才能发布。
- **确认与契约绑定**：每次确认绑定当时的属性契约哈希；契约一旦更新，已有确认立即失效并按新契约重算，草稿内依赖示例全部标记失效，不沿用旧结论。
- **失败回滚**：确认、保存或发布任一步失败（校验拦截、存储异常等）都会回到修订前内容并保留草稿；发布前自动快照，修订前内容可随时回溯。
- **操作留痕**：提案、确认、确认失效、发布、撤销、已发布组件的直接修改、失败回滚和归属迁移都会写入审计日志，且不随撤销/重做回退。
- 规范校验：检测重复属性、缺少键盘/读屏说明、空示例、失效属性引用和交互契约变化；发布修订前强制通过错误级校验。
- 失效传播与迁移：修改交互签名、删除属性或更新组件契约后，关联示例标记为待迁移；迁移操作（仅示例责任组）可清理已删除属性引用并更新版本。
- 版本差异：保存快照后可比较字段、属性与示例变化；保留最近 12 个快照。
- 主题与密度预览：支持浅色/深色，以及紧凑、标准、宽松三档密度。
- 代码示例复制与离线编辑：内容写入本地存储，刷新或断网后仍可继续编辑。
- 撤销重做：支持工具栏按钮，以及 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`。
- 键盘流程：`Cmd/Ctrl+K` 聚焦搜索，`Alt+1` 至 `Alt+6` 切换编辑区，`Alt+N` 新建组件，`Cmd/Ctrl+S` 保存版本。

## 协作流程说明

1. 在工具栏选择**当前小组**（规范组 / 无障碍组 / 平台组），后续编辑与确认都以该组身份记录。
2. 责任组编辑自己负责的区：直接生效；对已发布组件的直接修改会写入留痕。
3. 跨组编辑：改动进入该组件的**待审修订**草稿，已发布内容保持不变；与修订冲突的字段会被拒绝直接修改，避免发布时互相覆盖。
4. 在「6 修订与留痕」工作区查看改动差异、所需责任组与确认状态；两个责任组确认后**发布修订**。
5. 属性契约更新会使已有确认立即失效重算，需重新确认；发布失败（如校验不通过）回到修订前内容并保留草稿。

## 技术栈

- Lit 3
- TypeScript 5
- Spectrum Web Components
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认在源码配置的 Vite 端口运行，并监听 `0.0.0.0`。宿主机端口由项目根目录的 `docker-compose.yml` 统一映射为 `10028:80`。

## 类型检查、流程验证与生产构建

```bash
npm run typecheck
npm run verify
npm run build
npm run preview
```

`npm run verify` 在 Node 中运行 `scripts/verify-workflow.ts`，端到端验证权限隔离、跨组修订、两组确认、契约失效重算、失败回滚、草稿镜像和旧数据归属迁移。生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1028 .
docker run --rm -p 10028:80 sologsb-1028
```

镜像采用 Node 多阶段构建，最终由 nginx 提供静态内容并监听容器 `80`。容器不硬编码宿主端口。

## 数据说明

浏览器存储键为 `sologsb-1028-workspace-v1`。旧版本数据缺少责任组等字段时，加载会自动补默认归属（组件→规范组、属性→平台组、无障碍说明→无障碍组、示例→平台组）并写入留痕。清除站点数据会恢复到内置示例数据。
